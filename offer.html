1. Общие положения

GoFit уважает конфиденциальность пользователей и принимает необходимые меры для защиты предоставленной персональной информации.

Используя сайт GoFit и отправляя свои данные через формы обратной связи, пользователь подтверждает, что ознакомился с настоящей Политикой конфиденциальности.

2. Какие данные мы получаем

При отправке заявки через сайт пользователь может предоставить:

  • имя;
  • номер телефона;
  • другую информацию, которую пользователь самостоятельно указывает в форме.

3. Для чего используются данные

Предоставленные данные используются исключительно для:

  • обработки заявки;
  • связи с пользователем;
  • предоставления информации об услугах GoFit;
  • записи на тренировку или консультацию.

4. Обработка персональных данных

Отправляя заявку через сайт, пользователь добровольно предоставляет свои персональные данные и соглашается на их обработку для указанных в настоящей Политике целей.

5. Передача данных

GoFit не продаёт персональные данные пользователей и не передаёт их третьим лицам без соответствующего законного основания.

Если для обработки заявки используются сторонние сервисы связи, необходимые для выполнения запроса данные могут передаваться соответствующему сервису.

6. Защита информации

GoFit принимает разумные технические и организационные меры для защиты персональных данных от несанкционированного доступа, изменения, раскрытия или уничтожения.

7. Права пользователя

Пользователь вправе обратиться в GoFit по вопросам, связанным с обработкой его персональных данных, а также запросить их исправление или удаление в случаях, предусмотренных законодательством.

8. Изменение политики

GoFit оставляет за собой право изменять настоящую Политику конфиденциальности. Актуальная версия всегда публикуется на данной странице.

9. Контактная информация

По вопросам обработки персональных данных пользователь может связаться с GoFit через контактные данные, указанные на официальном сайте.
